# R8ILT STORE — Мультибрендовый магазин одежды ♰

Магазин оригинальной брендовой одежды для ценителей уличного, бойцовского и темного милитари стиля (**Pit Bull West Coast, Svastone, Белояр, Thor Steinar**).

## 🩸 Особенности магазина:
- **Концепция**: Мультибрендовый ритейлер оригинальной одежды от культовых производителей.
- **Бренды в каталоге**:
  - *Pit Bull West Coast* (Худи, штаны, спортивная и уличная одежда)
  - *Svastone* (Streetwear & Combat apparel, футболки, головные уборы)
  - *Белояр (Beloyar)* (Славянский стиль, тяжелый хлопок, кожаные ремни)
  - *Thor Steinar* (Nordic Heritage, карго брюки, зип-кофты)
- **Интерактивный каталог**:
  - Фильтрация по брендам в реальном времени.
  - Быстрый просмотр вещей (**Quick View**).
  - Избранное (**Wishlist**) и корзина с подсчетом суммы и сохранением в `localStorage`.
- **Дизайн**:
  - Глубокая темно-красная палитра и атмосферный готический неон.
  - Строгая типографика (*Syncopate, Cinzel, Space Mono, Inter*).

## 🚀 Как запустить:
Откройте `index.html` в любом браузере.
